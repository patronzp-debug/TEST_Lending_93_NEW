# Changelog

Всі помітні зміни в цьому проєкті будуть документуватися в цьому файлі.

## [1.0.0] - 2026-05-28

### Додано
- Каркас сайту (Next.js App Router, Tailwind CSS, TypeScript).
- Кінематографічні GSAP/Framer анімації (Hero, About, Equipment).
- Асиметричний Bento Grid для відображення вакансій.
- Преміальна рекрутингова форма з миттєвою Zod валідацією, анімованими помилками та автозбереженням чернетки у localStorage.
- Повна мобільна адаптація та плавний скролл (Lenis + GSAP bridge).
